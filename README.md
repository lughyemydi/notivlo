# notivlo

**Every subject, every deadline, in one quiet place.**

A revision app for A level: a notebook for each class, a week built around
what is actually due, and a home page that opens on the next thing to do.

- **Try it:** https://lughyemydi.github.io/notivlo/
- **Mac app:** [latest release](https://github.com/lughyemydi/notivlo/releases/latest)

This repository holds the published build — the landing page and the web app
as they are served. It is not the development tree.

## Status

Early beta, looking for testers. Feedback goes through the form on the site,
or open an issue here.
